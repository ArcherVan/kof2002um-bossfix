# kof2002um-bossfix

**《拳皇 2002 UM》玩家选用 BOSS 时的伤害补偿工具。**

不改游戏文件。双击一个启动文件，游戏正常起来；在同一个窗口里输入一个数字，你打出的伤害就按这个倍率放大。

Double-click one launcher, type a number in the same console, and outgoing player damage is scaled by that factor. It never touches files on disk and disappears when the game exits.

## 项目简介

《拳皇 2002 UM》里，玩家如果直接选用 BOSS（Omega Rugal、Krizalid、Clone Zero、Original Zero、Igniz 等），会明显感觉"打得没伤害"——官方削弱了 BOSS 的攻击力。本项目把这段差额补回来。

做法是在游戏进程内存里挂一个钩子，拦截"HP -= 伤害"这一条指令，在写回之前按倍率放大。因为只改运行时内存：

- **游戏文件零改动**，EXE 的 MD5 始终不变；
- **一个数字就能开关**，随时在"补偿"和"原版"之间切换；
- **进程退出即消失**，不留下任何持久化痕迹。

### 适合谁

| 项 | 说明 |
|---|---|
| 游戏 | Steam 版 / Code Mystics 移植版（其他 repack 见[兼容性](#兼容性与环境适配)） |
| 系统 | Windows 10 / 11，64 位 |
| Python | 3.8+，只用标准库，**不需要 pip 安装任何包** |
| 权限 | 普通用户通常够用；写不进去时用管理员身份运行 |
| 场景 | **仅单机**，不要用于联机对战 |

## 四步上手

给不想看长文档的人，全程约 5 分钟：

1. **装 Python**：到 [python.org](https://www.python.org/downloads/) 下载 64 位安装包，安装时勾上 `Add python.exe to PATH`。
2. **下载本项目**：页面右上角 `Code` → `Download ZIP`，解压到任意目录（例如 `D:\tools\kof2002um-bossfix`）。
3. **生成启动文件**：打开解压出的文件夹，在地址栏输入 `cmd` 回车，然后执行：

   ```bat
   kof.cmd shortcut
   ```

   游戏目录里会出现 `启动KOF2002UM.cmd`。若提示"没找到游戏"，改用在命令后面加游戏目录：`kof.cmd shortcut --game-dir "D:\你的游戏目录"`。

4. **双击 `启动KOF2002UM.cmd`**，等窗口出现 `kof>`，输入 `2` 回车。

之后每次玩都只需第 4 步。下面是每一步的详细说明和排错方法。

## 安装（详细）

### 第 1 步：确认系统

- Windows 10 或 11，**64 位**（32 位系统不支持）。
- 游戏已安装，并且能正常启动一次。Steam 版或解压版都行。
- 不需要联网，不需要安装任何额外运行库。

### 第 2 步：安装 Python

1. 打开 <https://www.python.org/downloads/>，点 **Download Python 3.x.x**（任意 3.8 以上版本均可）。
2. 运行安装包，**务必勾选最下方的 `Add python.exe to PATH`**，再点 `Install Now`。
3. 验证：按 `Win + R`，输入 `cmd` 回车，在窗口里敲：

   ```bat
   python --version
   ```

   看到 `Python 3.x.x` 即成功。

**装完仍然提示"不是内部或外部命令"**：先关掉命令提示符重新开一个（PATH 只在新的窗口生效）；还不行就重新运行安装包，选 `Modify` 勾上 PATH 那一项。

如果系统里已有 Microsoft Store 版 Python，`py -3 --version` 也能用，本项目的启动脚本会自动挑选可用的解释器，不用手动配置。

### 第 3 步：下载项目

- 有 git：

  ```bat
  git clone https://github.com/ArcherVan/kof2002um-bossfix.git
  ```

- 没有 git：在仓库页面点 `Code` → `Download ZIP`，解压。

放在哪个目录都可以，**中文路径和空格都支持**。解压后确认目录里能看到这些内容：

```
kof.cmd
src\
tools\
config.example.json
```

### 第 4 步：生成启动文件

打开这个文件夹（资源管理器中进入该目录），在**地址栏**里输入 `cmd` 回车，会直接在当前目录打开命令提示符，然后执行：

```bat
kof.cmd shortcut
```

正常输出：

```
已生成：D:\Games\THE KING OF FIGHTERS 2002 UM\启动KOF2002UM.cmd
源仓库：D:\tools\kof2002um-bossfix
```

它会自动找游戏目录（依次查 `config.json` 的 `game_exe`、Steam 库、本工具所在目录及其上一级）。

**提示"没找到游戏"**：手动指定一次游戏目录，路径改成你自己的：

```bat
kof.cmd shortcut --game-dir "D:\Games\THE KING OF FIGHTERS 2002 UM"
```

也可以把游戏 exe 的完整路径写进 `config.json` 的 `game_exe`（复制 `config.example.json` 为 `config.json` 再改），以后就不用管了。

> 启动文件里记录了本仓库的位置。**仓库搬家后要重新执行一次 `kof.cmd shortcut`**，否则它找不到程序，会退化成"只开游戏、不打补丁"。

### 第 5 步：验证

双击 `启动KOF2002UM.cmd`。首次运行会依次看到：

```
=== 拳皇 2002 UM 一键启动 ===

正在启动…
已启动：PID 21992
引擎已就绪（0.0s）
补丁已安装：代码洞 0x0C260000，3 处扣气点已接管
1P 气槽已补满 5 格
补丁状态：已安装   代码洞 = 0x0C260000
  0x00430D60  超必杀        e8 ...  OK
  0x00430DA3  MAX 曝气      e8 ...  OK
  0x0060AC51  通用扣气      e8 ...  OK
说明：只对 1P 免扣气，CPU 仍正常消耗。

全部完成，直接进游戏即可。
开始维持 1P 气槽（5 格）。
```

**注意：不要关这个黑窗口。** 它一边维持气槽，一边接收你的命令。最小化即可。

## 启动与使用

### 日常三步

1. 双击 `启动KOF2002UM.cmd`。
2. 等窗口出现 `kof>`（通常两三秒）。
3. 输入倍率，回车。例如 `2`。

游戏已经在运行时双击也一样：它会认出现有进程，只补打补丁，不会再开一个游戏。

### 窗口里能敲什么

所有操作都在这个窗口里完成，不需要另外开命令行：

| 输入 | 作用 |
|---|---|
| `2.5` | 设为 2.5 倍并开启（`x3`、`dmg 2`、`2倍` 都认） |
| `on` / `on 1.5` | 开启补偿；不带数字时用默认倍率（2.0，可在配置里改） |
| `off` | 关闭补偿，伤害回到原版（钩子保留，随时可再开） |
| `power` | 立刻把 1P 气槽补满 |
| `status` | 查看补丁状态、当前倍率、气槽格数 |
| `help` | 列出全部命令 |
| `quit` | 停止补气并退出（补丁仍有效；直接关窗口也一样） |

输入无法识别时不会报错，只会显示帮助。

### 一个完整例子

```
kof> status
补丁：已安装
1P 气槽：5 / 5
伤害倍率：关   2 倍

kof> 2.5
伤害补偿：开   倍率 = 2.50 （仅对"受击方=P2"即玩家打出的伤害生效）
kof>
```

倍率在**下一击**就生效，不用退出对战，也不用重开窗口。伤害钩子只在第一次敲数字时安装，之后一直有效。

### 关于那个黑窗口

- **关掉它**：停止自动补气，已经打好的补丁**仍然有效**，只是气槽掉下去不再自动补满。
- **最小化它**：正常运行，命令照样能敲。
- **游戏退出**：窗口会自动结束。

## 调整伤害倍率

### 推荐值

| 倍率 | 输入 | 说明 |
|---|---|---|
| 1.0 | `off` | 等同原版 |
| 1.5 | `1.5` | 轻微增强 |
| 2.0 | `2` | **推荐起点** |
| 2.5 | `2.5` | 偏强 |
| 3.0 | `3` | 建议上限，再高容易一击必杀 |

程序接受 0.1 ～ 16，超过 4 会提示一次但不阻拦。建议范围 **1.0 ～ 3.0**。倍率只对之后发生的伤害生效，不追溯已经打出去的血量。

### 校准（约 3 分钟）

倍率是经验值。想精确对齐，用练习模式的伤害数字对比，命令都在启动窗口里输：

1. 输入 `2`，进练习模式，P1 选你的 BOSS，P2 选血厚的普通角色并让它静止。
2. 固定站位，用**同一招**打 3 次，记下稳定值 `A`。
3. 输入 `off`，换一局，**P2 选同一个 BOSS 由电脑操作**，P1 站着挨同一招，记下 `C`。
4. `A` 比 `C` 小就调大，接近就合适，超过就调小。

### 玩普通角色之前

输入 `off`。

补偿不区分角色，开着就会放大你打出的**所有**伤害。

## 无限气

启动文件已经顺带装好了免扣气补丁：1P 放超必杀、曝气都不掉气，装一次整局有效，跨回合也保持。

- **只对 1P 生效**，CPU 仍然正常消耗气槽，不会出现对手无限放超必杀。
- 回合开始气槽被游戏重置时，启动窗口会在半秒内自动补满。
- 不需要任何操作，也不影响伤害倍率。

## 工作原理

### 为什么只能运行时改

这一版游戏的可执行文件里，`.text` 段在磁盘上是**加密**的（熵接近 8.0），启动后由加载器解密到内存并置为可执行。用十六进制编辑器改 EXE 里的一个字节 = 改密文，游戏大概率起不来。所以有效的改动只能发生在进程内——这也正是它天然可逆的原因。

### 钩子挂在哪

整场对战里，HP 的扣减集中在这一条指令上：

```
sub word ptr [eax+0x138], dx      ; HP -= 伤害
```

`eax` 是**受击方**对象，`dx` 是本次伤害，`0x138` 是 HP 字段。它只有一处，所以钩住它等于拿到了每一次真实伤害，不需要读屏幕、不需要截屏。

### 钩子怎么工作

安装时申请一块可执行内存（code cave），写入一段机器码，把原指令的前 5 个字节换成一条 `jmp` 跳过去执行，最后跳回原指令之后：

```
保存现场 → 记录本次命中 → 若 开关打开 且 受击方是 2P: dx = dx × 倍率
→ 恢复现场 → 执行原指令 → 跳回
```

三个细节：

- **倍率用定点数**（256 = ×1.0），避免浮点指令污染标志位；
- **开关和倍率都放在 cave 里**，改数字就是写内存，所以即时生效、不用重新挂钩；
- **原字节校验**：安装前比对目标地址的原始指令，版本不符时拒绝改动而不是盲写。

### 一个被推翻的结论

伤害落地前有一段后处理（`0x628200`–`0x628264`），看起来非常像"BOSS ×0.5 惩罚"。早期版本据此打了 4 个 NOP 补丁，实机字节校验全部通过——**但伤害毫无变化**。

改成在落地处挂钩、逐次记录 `(受击方, 伤害, 当前对象槽)` 后，采集 279 次命中的结论很干脆：那条链处理的**全部是受击方**，伤害序列 `11 → 5 → 2 → 1 → 1 → 1` 随连段递减，普通角色打一整局也一样。它是 2002UM 的**连段伤害衰减**，与 BOSS 无关。那组补丁已被彻底废弃。

修正后的认知：

| 机制 | 作用对象 | 状态 |
|---|---|---|
| 多段命中衰减（×0.5 / ×0.75） | 受击方 | 已定位，**未修改**（属正常机制） |
| CPU 用 BOSS 时的受击减伤 | CPU 侧 | 已观察，未修改 |
| **玩家选 BOSS 时的攻击力下降** | 攻击方 | 倍率与代码位置仍未定位 |

第三项就是本项目要对抗的东西。因为没定位到源头，所以不做"精确还原"，而是让你自己把倍率调到合适。完整分析见 [docs/01-原理与机制分析.md](docs/01-原理与机制分析.md)。

### 技术栈

| 层 | 用什么 | 用途 |
|---|---|---|
| 语言 | Python 3.8+ | 全部工具逻辑，只用标准库 |
| 进程操作 | `ctypes` + `kernel32` | `OpenProcess` / `ReadProcessMemory` / `WriteProcessMemory` / `VirtualAllocEx` |
| 注入代码 | 手写 x86 机器码（约 60 字节） | 无汇编器、无 DLL、无第三方依赖 |
| 启动脚本 | Batch（GBK 编码） | 自动挑选可用解释器、清理代理变量 |

## 配置说明

配置文件是仓库根目录的 `config.json`（UTF-8 JSON，可复制 `config.example.json` 得到）。不存在时用内置默认值；也可以用环境变量 `KOF_CONFIG` 指向任意路径。

**大多数用户不需要改任何一项。** 默认值对应 Steam 版。

| 字段 | 默认值 | 含义 | 何时需要改 |
|---|---|---|---|
| `process_name` | `KingOfFighters2002UM.exe` | 进程名，大小写不敏感 | repack 改了 EXE 名 |
| `game_exe` | 空 | 游戏 exe 完整路径；留空则自动扫描 | 生成启动文件时提示找不到游戏 |
| `steam_appid` | `222440` | 直接起 exe 失败时走 `steam://` 重试 | 换版本 / 留空禁用 |
| `hook_site` | `0x620902` | 伤害落地指令的运行时地址 | 版本不同、`doctor` 报字节不符 |
| `hook_orig` | `66 29 90 38 01 00 00` | 该处原始字节（校验用） | 同上 |
| `hook_back` | `0x620909` | 原指令之后的下一条地址 | 同上 |
| `obj_slot` | `0x21E3414` | 引擎"当前对象"全局槽 | 仅记录用，一般不改 |
| `player_obj` | `0x167D360` | 1P 角色对象地址 | 补偿不生效时 |
| `enemy_obj` | `0x167D580` | 2P 角色对象地址 | 同上 |
| `hp_offset` | `0x138` | 角色对象内 HP 偏移 | 一般不改 |
| `power_offset` | `0x1E3` | 气槽格数（0~5） | 一般不改 |
| `power_flag_offset` | `0x1EE` | "免耗气"标志位 | 一般不改 |
| `default_factor` | `2.0` | 窗口里输入 `on` 时用的倍率 | 想固定默认倍率 |
| `log_file` | `hookdmg_log.txt` | 录制日志文件名 | 想换位置 |

地址字段可以写 `"0x620902"` 或十进制整数。改完执行 `kof.cmd config` 确认已生效，再用 `kof.cmd doctor` 确认字节匹配。

**换版本怎么找新地址**：见 [docs/01-原理与机制分析.md](docs/01-原理与机制分析.md) 的定位方法一节。

## 兼容性与环境适配

完整矩阵与排查流程见 [docs/03-兼容性与环境适配.md](docs/03-兼容性与环境适配.md)。

### 已确认可用的版本

| 版本 | EXE 大小 | MD5 | 状态 |
|---|---|---|---|
| Steam / Code Mystics（默认配置） | 4,748,304 | `e7a78eb4f724f65f12084bfc6e12420b` | 已验证 |

其他 repack 通常保留相同的代码结构（同一份 PS2 二进制重编译而来），但加载基址或对象地址可能不同。`kof.cmd doctor` 报"钩子点字节与预期一致"即可直接用；报"不符"则按[配置说明](#配置说明)调整。

### 环境相关

| 情况 | 说明 |
|---|---|
| 路径含中文或空格 | 支持，启动文件全程使用绝对路径并加引号 |
| 多版本 Python 共存 | 启动脚本按 `py -3` → `python` → `python3` 顺序探测 |
| 无管理员权限 | 通常可用；`doctor` 报读写失败时用管理员 |
| 开着代理 / 加速器 | 不影响。启动文件会先清空 `HTTP_PROXY` 等变量并设 `NO_PROXY=*`，避免游戏继承代理 |
| 多开游戏 | 自动挑有窗口的那个实例 |

## 已知限制

1. **只对 1P 位置生效。** 判定条件是"受击方 == 2P 对象"，即你作为 1P 攻击时。你在 2P 位置不会生效。
2. **不区分角色。** 它不知道你是不是在用 BOSS，开着就放大你打出的所有伤害。玩普通角色前输入 `off`。
3. **每次都要重新打补丁。** 改动只在游戏进程内，退出即消失。所以请始终用启动文件开游戏，不要直接点游戏图标或从 Steam 启动——那样补丁不会被加载。
4. **倍率是补偿而非还原。** "玩家选 BOSS 时攻击力下降"的确切倍率尚未定位，本工具是用可调倍率逼近，不是精确恢复。
5. **不改变 CPU 侧行为。** CPU 用 BOSS 时的受击减伤保持原样。
6. **连段衰减保持原样。** 早期版本曾误改这一段，现已移除；连段伤害仍会正常递减。
7. **版本脆弱。** 地址与字节绑定具体版本，换版本会安全拒绝（不会误写），需要重新对位。
8. **可能触发杀软。** 它会 `OpenProcess` + `WriteProcessMemory`，属调试器行为，加白名单即可；只操作游戏进程。
9. **仅单机。** 不要在联机对战中使用。
10. **不修改任何文件。** 游戏 EXE 与 Data 目录始终原样，可随时用 MD5 校验。

## 常见问题

**Q：双击启动文件，窗口一闪就没了？**

看它最后一行是什么。常见两种：找不到 Python（回到[安装](#安装详细)第 2 步）、仓库路径变了（重新执行 `kof.cmd shortcut`）。也可以右键启动文件 → `编辑`，查看里面的 `KOF_HOME` 是否指向真实目录。

**Q：窗口里输入 `2`，但伤害没变化？**

按顺序查：① 输入 `status`，倍率是否显示"开 2 倍"；② 你是在 1P 位置、打的是电脑吗（补偿只对 1P 打出的伤害生效）；③ 游戏是不是在这次启动文件之外打开的（那样没有补丁）；④ 是否打中了"格挡"或无敌状态。

**Q：每次开游戏都要重新输倍率吗？**

是的，补丁只在这次进程内有效。想省事就用 `on`（不带数字，走 `config.json` 里的 `default_factor`，默认 2.0）。但注意 `on` 依然要手动敲一次——没有"开机自动放大"的设计，避免你之前忘了关。

**Q：关掉黑窗口会怎样？**

补丁仍然有效，伤害照旧放大；只是不再自动补气，气槽掉下去不会自己回满。想恢复自动补气，重新双击启动文件即可。

**Q：能不能一次性永久生效？**

不能。改动只在该游戏进程的内存里，关闭游戏即消失。也正因为如此，它不需要"卸载"，不会留下痕迹，随时可以恢复原版。

**Q：会被 Steam 判定为作弊吗？**

它不改文件、不联网，只读写本机游戏进程内存。但本作是单机向移植，请勿用于任何联机场景。

**Q：开了代理 / 加速器会影响启动吗？**

不影响。启动文件在拉起游戏前会清空 `HTTP_PROXY`、`HTTPS_PROXY`、`ALL_PROXY` 等变量并设 `NO_PROXY=*`，避免游戏进程继承代理后卡在连接上；启动器本身不联网。系统级代理（Clash TUN 模式等）照常由系统处理。

**Q：游戏窗口总是自动最小化？**

本作失去前台焦点会自我最小化，属正常行为，点回前台即可，与工具无关。

**Q：提示"落地指令字节与预期不符"？**

版本不匹配，或上次留下了失效的跳转。先重跑一次启动文件（会自动修复）；仍报错说明版本不同，跑 `kof.cmd doctor` 把输出发到 Issues。

**Q：提示 `AttributeError: class must define a '_type_' attribute`？**

Python 环境的 `_ctypes.pyd` 与解释器版本不匹配（多见于自动更新过程中）。按顺序试：再跑一次 → 换另一个解释器（`py -3` / `python`）→ 重装 Python。
