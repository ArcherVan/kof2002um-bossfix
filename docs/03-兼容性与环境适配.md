## 2. Python 环境适配

### 2.1 探测顺序

`kof.cmd` 启动时按顺序尝试，第一个能 `import ctypes` 的就用：

```
py -3   →   python   →   python3
```

命中即停，**不需要手动配置 PATH**，也不会因为系统里有多个 Python 而选错版本。

### 2.2 各类环境

| 环境 | 预期 | 注意 |
|---|---|---|
| python.org 官方安装 | ✅ | 安装时勾选 "Add Python to PATH" |
| Microsoft Store 版 | ✅ | `py -3` 通常可用；个别情况沙箱限制进程访问 |
| Anaconda / Miniconda | ✅ | 用 `conda activate <env>` 后的命令行 |
| 嵌入式 / 便携版 | ⚠️ | 需把目录加入 PATH，或直接 `绝对路径\python.exe src\hookdmg.py ...` |
| 多版本共存 | ✅ | `py -3` 取最新；要固定版本就改 `kof.cmd` 第一段探测 |
| WSL / MSYS2 的 python | ❌ | 无法访问 Windows 进程，必须用 Windows 版解释器 |

### 2.3 指定解释器运行

不想依赖批处理时，直接用绝对路径：

```bat
"C:\Python312\python.exe" src\hookdmg.py install
"C:\Python312\python.exe" src\hookdmg.py on 2
```

功能完全一致，`kof.cmd` 只是替你挑解释器和拼路径。

### 2.4 依赖

运行时**零第三方依赖**，只用标准库：`ctypes`、`struct`、`os`、`sys`、`json`、`subprocess`、`time`。

`requirements.txt` 因此为空（见该文件的说明）。不要为"保险"去 `pip install` 任何东西。

## 3. 权限与安全软件

### 3.1 权限

| 情形 | 结果 |
|---|---|
| 普通用户 + 游戏同用户启动 | ✅ 正常 |
| 普通用户 + 游戏以管理员启动 | ❌ `OpenProcess 失败，错误码 5` → 用管理员重开命令行 |
| 管理员 | ✅ |

判断方法：`kof.cmd doctor` 的"权限"一节。

### 3.2 杀毒软件

工具会调用 `OpenProcess` / `WriteProcessMemory` / `VirtualAllocEx`，这些是调试器与注入的典型 API，**部分杀软会拦截或报警**。

- 处理：把项目目录加入白名单，或临时放行当前命令行窗口；
- 它只操作 `KingOfFighters2002UM.exe` 一个进程，不联网、不加载驱动、不写系统目录；
- 唯一会写的文件是工作目录下的 `hookdmg_log.txt`。

### 3.3 反作弊 / 联机

本项目仅面向单机。本作是单机向移植，无 VAC 服务器对战；**不要**在联机或排行榜场景使用。

## 4. 环境细节

### 4.1 路径含中文或空格

支持。`kof.cmd` 用 `%~dp0` 解析绝对路径并全程加引号。

### 4.2 批处理是 GBK 编码

`kof.cmd` 以 **GBK（CP936）+ CRLF** 保存，因为在中文 Windows 下 `cmd.exe` 按系统代码页解析批处理文件；若存为 UTF-8，中文注释会被撕裂成非法命令。

- 在中文 Windows 的 cmd 窗口里显示正常；
- 在英文 Windows（CP437）下中文提示会乱码，但**命令本身仍能执行**——脚本逻辑与文字无关；
- 用 VS Code 编辑时请选择 GBK 重新打开，否则保存会把编码改回 UTF-8。

### 4.3 多开 / 残留进程

游戏多开时 `install` 会：

1. 枚举所有同名进程；
2. 优先选**有可见窗口**的那个；
3. 打印"检测到 N 个游戏进程，选用有窗口的 PID …"。

如果选错了（比如窗口最小化），先关掉多余实例。

### 4.4 窗口自动最小化

本作失去前台焦点会自我最小化。这不是故障，也不影响钩子（钩子工作在进程内存，与窗口状态无关）。`doctor` 里显示"(无可见窗口/已最小化)"属正常。

## 5. 为新版本对位

### 5.1 流程

```bat
rem 1. 确认二进制
certutil -hashfile "D:\游戏目录\KingOfFighters2002UM.exe" MD5

rem 2. 复制配置模板
copy config.example.json config.json

rem 3. 修改地址后验证
kof.cmd config
kof.cmd doctor
kof.cmd install
kof.cmd watch 60
```

### 5.2 怎么找地址

| 要找什么 | 方法 |
|---|---|
| 伤害落地指令 | 搜特征字节 `66 29 90 38 01 00 00`；偏移变了就搜 `66 29 ?? <偏移> 00 00` |
| 原始字节 | 用任意反汇编器在候选地址取 7 字节 |
| P1/P2 对象地址 | 搜 `mov dword ptr [0x21E3414], imm32`，通常会连续出现两条写入 |
| HP 偏移 | 在对象附近找"随受击单调减少的 int16" |

细节与方法论见 [01-原理与机制分析.md](01-原理与机制分析.md) 第 6 节。

### 5.3 配置字段对照

见 [README 的配置说明表](../README.md#配置说明)。改完务必跑 `kof.cmd config` 确认加载来源不是 `built-in defaults`。

## 6. 症状速查

| 症状 | 最可能原因 | 处理 |
|---|---|---|
| `未找到可用的 Python 3` | Python 未装 / 未进 PATH | 装 3.8+ 并勾选 Add to PATH，重开命令行 |
| `未找到 KingOfFighters2002UM.exe` | 游戏没开，或进程名不同 | 先开游戏；改名了就改 `process_name` |
| `落地指令字节与预期不符` | 版本不同；或上次残留 | 再跑一次 `install`；仍报错则重新对位 |
| `OpenProcess 失败，错误码 5` | 权限不足 | 管理员身份重开命令行 |
| `ReadProcessMemory 失败` | 权限或已退出 | 确认游戏在跑；管理员重试 |
| `钩子未按当前版本安装` | 没 `install` 就执行了 `on`/`show` | 先 `install` |
| 显示"开"但伤害没变 | 倍率 ≤1；或不在 1P；或没打中 | `kof.cmd show` 核对，确认打的是电脑 |
| 伤害变了但普通角色也变强 | 补偿对所有人生效 | 属已知限制，玩普通角色前 `off` |
| 游戏崩溃 | 钩子失效（多见于换版本后直接 `on`） | 重启游戏 → `kof.cmd doctor` → `install` |
| 中文显示乱码 | 控制台代码页 | `chcp 936` 后重跑；或用 Windows Terminal |
| `_type_` AttributeError | Python 的 `_ctypes.pyd` 与版本不匹配 | 换解释器或重装 Python |

## 7. 提交你的版本指纹

如果你成功适配了新版本，欢迎提 PR 补充矩阵：

```bat
kof.cmd doctor > doctor.txt
```

PR 内容建议包含：

1. `doctor.txt` 全文；
2. EXE 大小与 MD5；
3. `config.json` 中与默认值不同的字段；
4. 实测结论（`watch` 打几下是否按倍率放大）。

格式参照上方[兼容矩阵](#1-版本兼容矩阵)。
