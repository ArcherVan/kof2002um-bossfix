# 安装与使用

> 照着做即可，全程不需要 pip、不需要联网、不需要改游戏文件。

---

## 一、首次安装（一次性，约 3 分钟）

### 1. 放到任意目录

```bat
git clone https://github.com/ArcherVan/kof2002um-bossfix.git
cd kof2002um-bossfix
```

没有 git 就下载 ZIP 解压。目录可以含中文和空格，不影响运行。

### 2. 确认 Python

```bat
python --version
```

- 有输出（3.8 以上）→ 跳过下一步。
- 提示"不是内部或外部命令"→ 去 python.org 装 3.8+，**安装时勾选 "Add Python to PATH"**，装完重开命令行。
- 不确定装没装，直接跑第 3 步的自检，它会告诉你。

### 3. 环境自检

```bat
kof.cmd doctor
```

预期输出：

```
-- 系统 --
  [OK]   平台：Windows 11
  [OK]   架构：64bit（本作是 64 位程序）
-- Python --
  [OK]   版本：3.12.4  (...)
  [OK]   ctypes 与 kernel32 可用
-- 权限 --
  [WARN] 非管理员权限；多数情况够用...
-- 配置 --
  [OK]   来源：built-in defaults
-- 游戏进程 --
  [WARN] 未检测到 KingOfFighters2002UM.exe（未启动...）

  结论：环境可用 ✔
```

`[WARN]` 不影响使用，只有 `[FAIL]` 需要处理。

### 4. （可选）按版本调整配置

默认值对应 Steam 版。换了 repack 就先：

```bat
copy config.example.json config.json
```

再编辑 `config.json`，字段含义见 [README 配置说明](../README.md#配置说明)。不确定就先跳过。

## 二、日常使用

### 双击启动（推荐）

执行一次：

```bat
kof.cmd shortcut
```

游戏目录里会多出 `启动KOF2002UM.cmd`，以后双击它即可——启动游戏、打补丁、补满气槽全自动，开着代理也不受影响。

### 在启动窗口里直接改（不用另开命令行）

双击启动后那个黑窗口不会关，它停在 `kof> ` 提示符上边补气边等你输入，边玩边敲即可：

| 输入 | 作用 |
|---|---|
| `2.5` | 设为 2.5 倍并开启（`x3`、`dmg 2`、`2倍` 也认） |
| `on` / `on 1.5` | 开启补偿；不带数字沿用当前倍率 |
| `off` | 关闭补偿（钩子保留） |
| `power` | 立刻补满 1P 气槽 |
| `status` | 查看补丁、倍率、气槽 |
| `help` | 帮助 |
| `quit` | 停止补气并退出 |

- 倍率在**下一击**生效，不用退对战，也不用重开窗口。
- 第一次敲数字时会自动装伤害钩子（几十毫秒），之后一直有效。
- `quit` 或直接点叉关闭窗口，补丁仍留在游戏进程里，只是不再自动补气。

### 进阶：命令行启动（日常不需要）

不想用启动文件、或需要排错时，可以直接敲命令。效果和双击启动文件一致：

```bat
kof.cmd launch
```

留在窗口里维持气槽，同样能敲 `2.5` / `off` 这类命令。想要伤害补偿同时开用 `kof.cmd launch --dmg 2`。
游戏已经在跑的时候执行同一条命令也不会开第二个，它只补打补丁。

> 关掉控制台窗口不影响已打好的补丁，只是不再自动补气。

### 进阶：分步操作（游戏已经开着时）

#### 第 1 步：启动游戏

正常启动即可（Steam 或直接跑 EXE）。进入对战、选人界面、练习模式都能装，只要进程已经起来。

#### 第 2 步：加载

```bat
kof.cmd install
```

成功标志（任一句）：

```
钩子已安装：cave=0x030A0000  钩子点=0x00620902
钩子已存在，直接认领：cave=0x030A0000
```

重复执行不会出错，这是设计如此。

#### 第 3 步：开启补偿

```bat
kof.cmd on 2
```

输出：

```
伤害补偿：开   倍率 = 2.00 （仅对"受击方=P2"即玩家打出的伤害生效）
```

立刻生效，不需要重开对局。完成，进游戏打即可。

> **顺序不能颠倒**：`install` 必须在游戏启动之后。游戏关闭后需重做这三步。

## 三、调整数值

### 常用倍率

**双击启动的窗口里不用敲 `kof.cmd`**，直接输数字回车即可；从别的命令行调才用下面的写法：

```bat
kof.cmd on 1.5     # 轻微增强
kof.cmd on 2       # 推荐起点
kof.cmd on 2.5     # 偏强
kof.cmd on 3       # 建议上限
kof.cmd off        # 回到原版
```

- 支持小数（`1.7`、`2.3`），实际精度 1/256；
- 程序接受 0.1 ～ 16，建议范围 1.0 ～ 3.0，再高在极端招式上可能一击必杀；
- 只影响之后的伤害，不追溯。

### 随时查看

```bat
kof.cmd show       # 开关 + 倍率
kof.cmd status     # 钩子健康度 + 双方 HP + 命中计数
```

### 生效范围

- **只放大 1P 打出去的伤害**，电脑打你的伤害不受影响；
- 只对 1P 位置有效，2P 位置不生效；
- 连段中每一段都按同一倍率放大。

---

## 四、校准倍率（约 3 分钟）

倍率是经验值。想精确对齐，用练习模式自带的伤害数字：

| 步骤 | 操作 | 记录 |
|---|---|---|
| 1 | `kof.cmd on 2`，进 PRACTICE 模式 | — |
| 2 | P1 选你的 BOSS，P2 选血厚的普通角色并让它静止 | — |
| 3 | 固定站位，同一招打 3 次（推荐站重脚） | 稳定值 `A` |
| 4 | `kof.cmd off`，换一局：**P2 选同一个 BOSS 由电脑操作**，P1 站着挨同一招 | 参照值 `C` |

判定：

| 现象 | 处理 |
|---|---|
| `A` 明显小于 `C` | 调大，如 `on 2.5` |
| `A` 与 `C` 接近 | 就用这个倍率 |
| `A` 明显大于 `C` | 调小，如 `on 1.6` |

调好后把该值写进 `config.json` 的 `default_factor`，以后 `kof.cmd on` 不带参数就用它。

## 五、记录伤害数值

不想靠肉眼读数字时：

```bat
kof.cmd watch 120      # 实时打印 120 秒，只在当前窗口显示
kof.cmd rec 300        # 录制 300 秒，同时写入 hookdmg_log.txt
```

`rec` 会先等游戏启动（最多 15 分钟），游戏一出现自动接上；游戏退出则自动停止。

记录样例：

```
  #12   t= 14.3s  伤害=11   (0x00B)  受击=0167D580  P2
  #13   t= 15.1s  伤害=5    (0x005)  受击=0167D580  P2
```

`受击=P2` 表示这是你打出去的伤害（补偿生效范围）。

## 六、关闭与还原

| 目的 | 命令 | 影响 |
|---|---|---|
| 临时关闭 | `kof.cmd off` | 伤害立刻回原值，钩子保留，可再 `on` |
| 彻底卸载 | `kof.cmd uninstall` | 逐字节还原并释放内存 |
| 完全恢复 | 关闭游戏 | 所有改动都在进程内，退出即消失 |

换普通角色、打剧情、录素材前，执行一次 `off` 就够了，不必卸载。

## 七、无限气（可选）

和伤害补偿互不影响，可以同时使用。

### 推荐：装补丁

```bat
kof.cmd power patch
```

或者干脆用 `kof.cmd launch`——它默认就会装这个补丁并持续补满气槽，什么都不用敲。

装一次，整局有效，跨回合不用重跑。装完会打印：

```
补丁已安装：代码洞 0x06200000，3 处扣气点已接管
1P 气槽已补满 5 格
补丁状态：已安装   代码洞 = 0x06200000
  洞内机器码  3d 60 d3 67 01 74 06 fe 88 e3 01 00 00 c3
  0x00430D60  超必杀        e8 9b f2 dc 05 90  OK
  0x00430DA3  MAX 曝气     e8 58 f2 dc 05 90  OK
  0x0060AC51  通用扣气       e8 aa 53 bf 05 90  OK
```

三处扣气点：超必杀结束、MAX 曝气、通用扣气。补丁把它们改成跳转到同一段代码，代码里只对 1P 跳过扣减，**CPU 仍正常消耗气槽**，不会出现对手无限放超必杀。

还原：

```bat
kof.cmd power unpatch
```

### 临时方案：只改数值

```bat
kof.cmd power on 5        1P 补满 5 格 + 免耗气标志
kof.cmd power set 0 p2    对手没气
kof.cmd power show        查看双方血量、格数、标志
```

这条只写内存数据，不改代码，代价是游戏重置气槽后要重跑一次。

### 注意

- 补丁按"1P 对象地址"判断，所以只在 **1P 位置**有效。2P 位置不会生效。
- 气槽上限是 5 格。
- 补丁和伤害钩子都活不过游戏退出，重开游戏要重新执行。

## 八、MAX2 超必杀

原版要放 MAX2，必须同时满足"气槽 ≥ 3 格"和"体力 ≤ 30%"。启动文件默认把第二个条件去掉了，气槽够就能发。

### 查看与还原

```bat
kof.cmd max2 show        查看当前是原版还是已解除
kof.cmd max2 unpatch     还原成原版（恢复残血限制）
kof.cmd max2 patch       重新解除
```

### 原理

判定在 `0x641CD0`，末尾三行是：

```
00641CF2  movzx eax, word ptr [ecx+0x138]   ; 读体力
00641CF9  sub   eax, 0x24                   ; 体力 - 36（36/120 = 30%）
00641D03  jle   0x641D0A                    ; <= 0 才放行，否则按"招式不可用"处理
```

把 `jle`（`7E 05`）改成 `jmp`（`EB 05`）：两个字节，指令长度不变，不申请代码洞，也不需要重启游戏。

### 注意

- **气槽 3 格的门槛没有动**，MAX2 本来就要 3 格。
- 这段判定 1P 与 CPU 共用，所以电脑气槽够时也不再受血量限制。AI 很少主动选 MAX2。
- 不想用就在启动时加 `--no-max2`，或执行 `kof.cmd max2 unpatch`。

## 十、卸载干净

1. `kof.cmd uninstall`（游戏运行时执行，还原内存）
2. 关闭游戏
3. 删除整个项目目录即可，系统里没有任何残留（不写注册表、不装服务、不改 PATH）

想确认游戏文件完好：

```bat
certutil -hashfile "D:\游戏目录\KingOfFighters2002UM.exe" MD5
```

正常值 `e7a78eb4f724f65f12084bfc6e12420b`。
